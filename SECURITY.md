# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within RepoMind AI, please do **not** open a public issue. Instead, report it privately to our security team:

- **Email:** `security@repomind.ai`
- **Response Time:** We aim to acknowledge reports within 48 hours and provide a timeline for remediation.

Please provide:
1. A description of the vulnerability.
2. Steps or proof-of-concept script to reproduce.
3. Potential impact on users or infrastructure.

Thank you for responsibly disclosing security vulnerabilities.
